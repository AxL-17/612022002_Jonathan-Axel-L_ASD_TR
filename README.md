# Dungeon of ASD

- Nama: Jonathan Axel L
- NIM: 612022002

## Deskripsi
Game RPG konsol berbasis dungeon, dibuat dengan Bahasa C.

## Fitur
- Register, login, logout
- Battle, inventori (sorting dan searching)
- Undo langkah (stack), turn order (queue)
- Pencarian item (hash table), bestiary (BST)
- Peta dungeon (graph, BFS dan DFS)

## Kompilasi
gcc src/*.c -Iinclude -o app

## Menjalankan
./app   (Windows: app.exe)
